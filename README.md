# Сайт для быстрого и удобного создания резюме
- [exxbtw.github.io](https://exxbtw.github.io/)

## Функции

- **Редактируемые текстовые поля**: Пользователь может изменять содержимое резюме в реальном времени.
- **Скачивание в PDF**: Встроенная кнопка позволяет скачать текущую версию резюме в формате PDF.
- **Эффект Material Wave**: Реализован эффект волны при клике на элементы.
- **Хранение изменений**: Внесённые изменения сохраняются в `localStorage` и восстанавливаются при обновлении страницы.
- **Адаптивность**: Страница корректно отображается на мобильных устройствах и различных разрешениях экрана.
  
## Использованные инструменты

- **HTML**: Структура веб-страницы.
- **CSS**: Стили для оформления страницы, включая анимации.
- **JavaScript**: Логика взаимодействия с элементами и генерация PDF.
